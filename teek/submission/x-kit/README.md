## Pinned post

Post this as a short thread and pin the first one. Attach the demo video to the first post if it's ready.

1/
Token launches on Solana are a speed race, and bots win it. They buy in the first second and everyone else pays more.

We built Teek to take the race away. Private bids, one shared opening, built on @magicblock and @MeteoraAG.

2/
How it works. The creator publishes rules that can't change. Buyers deposit and bid privately in MagicBlock's Private Ephemeral Rollup, so nobody can see anyone else's bid while bidding is open.

3/
When bidding closes, one transaction creates the Meteora pool and buys with everyone's money at once. Everyone pays the same price, and nobody can trade before the group because the pool didn't exist a moment earlier.

4/
If the launch doesn't reach its minimum, there's no pool and everyone takes their deposit back. We ran both endings on devnet and the proof is public.

5/
Try it yourself with a demo wallet and free test tokens. No real money involved.
